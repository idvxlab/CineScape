# 参数 → 语义 → 渲染 映射表

意图驱动镜头语言编辑器的双向映射:
**意图 → 参数**(后端多智能体推理)与 **参数 → 意图/画面**(编辑器反向映射)。
本表记录后者:用户在 3D 编辑器里调的连续参数,如何① 标注成镜头语言语义、② 反向映射成后端 patch 文字、③ 驱动即梦 image2image 重摄关键帧。

## 数据流

```
3D 编辑器(连续 SevenDims)
   │  semantics.ts        → 语义标注(界面显示)
   │  schemeMap.dimsToPatch → 细粒度文字 patch(每镜)
   ▼
POST /sessions/{id}/edit  → 写进方案(_EDITABLE_FIELDS,LLM 复校)
   ▼
POST /sessions/{id}/render → 即梦 image2image,优先用 frame_edit_hint
   ▼
关键帧 PNG(回到 Shot Script)
```

> 关键帧实际由 **frame_edit_hint(自然语言)** 驱动,十维字段为辅。所以"细粒度"取决于 hint 文字里带多少精确数值 —— 现已覆盖全部视觉维度并带具体数值(度 / mm / f值 / % / K)。

## 视觉维度(进关键帧 frame_edit_hint)

| SevenDims 字段 | 编辑器输入(范围) | 界面语义(semantics.ts) | 后端 patch 字段 | 细粒度映射文字(schemeMap) |
|---|---|---|---|---|
| `distanceM` (+`composition.zoom`) | 1–26 m | 孤寂·渺小 ↔ 亲密·情绪 | `shot_size` | `大远景(相机距主体约15.0m,主体约占画面高14%)` —— 档位 + 实距 + 主体占比% |
| `angle.yaw` 水平绕转 | −180..180° | 正面·直面 / 侧面·旁观 / 背向·反观 | 并入 `angle` | `水平机位右前方斜侧(orbit 45°)` —— 方位 + 精确度数(**之前完全没映射**) |
| `angle.pitch` 俯仰 | −90..90° | 仰视·权力 / 平视·客观 / 俯视·渺小 | `angle` | `垂直角度中等仰拍·低角度(tilt −25°)` —— 强度 + 方向语义 + 精确度数 |
| `focal.mm` 焦距 | 16–135 mm | 广角·张力 ↔ 长焦·凝视 | `focal_length` | `50mm(标准·近人眼)` —— 精确 mm + 透视特性 |
| `focal.dof` 景深 | 0–1 | 浅·聚焦情绪 ↔ 深·交代环境 | `depth_of_field` | `约 f/5.6(背景强虚化·主体剥离)` —— **映射成光圈 f 值** + 特性 |
| `composition.focus.x/y` 构图 | 0–1 / 0–1 | 居中·稳定 / 偏置·留白张力 | `composition` | `主体左三分·纵向居中(横33%/纵50%,上留白50%,前留白67%)` —— **精确百分比**(之前只 3 档) |
| `lighting.keyPct/temperature/softness/spread/pos` 光照 | 各 0–100 / 0–1 | 低调压抑 / 高调明快 + 冷暖软硬 | `lighting` | `低调(暗部为主·压抑神秘)·冷色温~5100K·硬光·聚光·主光高位左侧(强度30%)` —— **5 个子参数全量**(之前完全没映射) |
| `color.look/contrast/saturation` 调色 | look + 各 −50..50 | 冷调忧郁 / 暖调欢快 + 对比/饱和 | `color_tone` | `Cool(冷调·疏离忧郁)·高对比(+30)·低饱和(−20)` —— look + **对比/饱和数值**(之前只发 look 名) |

## 时间维度(不进关键帧,进视频 /animate)

| 字段 | 范围 | 语义 | patch 字段 | 映射文字 |
|---|---|---|---|---|
| `movement.type` 运镜 | Static/Dolly/Pan/… | 推进·介入 / 拉远·孤寂 … | `movement` | `Dolly In(推进·逼近介入)` |
| `rhythm.curve` 节奏 | 速度曲线 | 急促 / 舒缓 | `rhythm` | `5.0s · 渐快·加速推向高潮`(由曲线趋势判定) |
| `movement.durationSec` 时长 | 0.5–12 s | 急促紧张 / 舒缓沉思 | `duration` | `5.0s(平稳·自然叙事)` |

## 细粒度说明

- **保留精确数值**:焦距 mm、俯仰/水平度数、构图百分比、对比/饱和数值、色温 K、光强 %、时长 s;景深映射为 **f 值**(`[1.4,2,2.8,4,5.6,8,11,16,22]` 按 dof 取档)。
- **语义档位**:景别、透视特性、光性等用少量语义档(更符合电影术语 + 便于图像模型理解),但都附带精确数值。
- **本次补全**:水平机位(orbit)、光照全部子参数、对比度/饱和度数值、构图精确百分比、节奏曲线趋势 —— 之前这些**完全没进渲染**,现已全部映射。

## 已知边界

- 即梦十维里**无独立"水平机位"字段**,故水平 orbit 并入 `angle`(文字描述)+ 写进 hint。
- 关键帧是 **image2image 从固定底图重摄**:小幅改动(角度/色调/景深/光照)可体现;"中景→大远景"等需要凭空生成底图外环境的大幅改动,受底图限制,效果有限。
- 最终画面是图像模型对 prompt 的**理解**,非确定性渲染,不保证逐数值精确遵循。
