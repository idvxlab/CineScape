# 术语表（Glossary）

统一用语。新文档遇到这些词用同一含义，不另造同义词。

| 术语 | 含义 |
|---|---|
| **设计空间** | 系统唯一的审美与知识来源 = 「意图本体 v3」+「知识卡」（方案库经飞轮成长后充当检索增强）。 |
| **意图本体 / 本体 (v3)** | 导演意图分类法：12 一级意图 × 56 二级意图，带 A/B 类型、双极轴、值集、作用域、易混淆判别规则。见 [`domain/ontology-spec.md`](domain/ontology-spec.md)。 |
| **一级意图 / 二级意图** | 本体的两级结构。一级=维度（如 信息管理），二级=受控词表取值（code 如 `8.3`）。 |
| **A/B 类型** | A=导演构成性意图（画面上可验证的安排）；B=观众效应性意图（要在观众心里发生的反应）。B 是目的、A 是手段。 |
| **知识卡** | 挂在每个二级意图上的电影语法卡：机制 + 十参数候选手法 + 经典参照。纯推理生成的知识锚点（ADR-0010）。 |
| **方案库** | "意图标签 + brief → 镜头脚本"的记录集合，由飞轮回写积累；是检索增强的来源（可选），不在生成主路径上。 |
| **Intent State** | 当前推测的用户意图：`dimensions`（一级意图 → 定性状态）+ `key_dimensions` + `brief` + `tags`。 |
| **维度状态** | 定性标签：`open / leaning / resolved / conflicting / blocked_by`。无数值置信度。 |
| **要紧维度集 (key_dimensions)** | 对当前意图重大的维度集合，黏滞维护；收敛判定只看它。 |
| **brief** | 收敛时合成的一段有画面感的创作描述，生成阶段的唯一意图陈述。 |
| **tags** | 收敛产出 = 选中的二级意图 code 列表（如 `["3.4","10.2"]`）。受控词表 = 本体二级 code。 |
| **收敛** | 对齐阶段结束、可进入生成的判定。机制见 [ADR-0003](decisions.md)。 |
| **易混淆判别规则** | 7 组（A-G）区分易混意图的规则；`probe` 是可直接抛给用户的判别问题，critic 用它查误标。 |
| **双极轴** | 成对互斥的二级意图（6.1↔6.2、10.2↔10.3、11.1↔11.2），对齐渲染为滑块，critic 查两极冲突。 |
| **策略直推 (Strategy)** | 生成第一步：对收敛意图组合在设计空间内枚举 ≤3 个机制路径（ADR-0010，取代"从范例归纳"）。 |
| **方向 (Direction)** | 一条机制路径：`{dominant_intents, mechanism, core_technique}`;主导机制族不同才算不同方向。 |
| **三层推理链** | B 效果意图 → 心理/知觉机制 → A 构成手段 → 十参数。生成与审校共用的推理纪律。 |
| **plan→detail** | 生成第二步：先出镜头序列骨架（beats），再把每 beat 填成十参数镜头。 |
| **十参数** | 单镜头的参数：景别 / 构图 / 角度 / 运镜 / 焦距 / 景深 / 光影 / 色彩 / 节奏 / 时长。 |
| **serves** | 每镜声明其服务的二级意图 code 列表；critic 确定性校验其必须落在 tags+dominant_intents 内。 |
| **参数耦合三组** | 空间/画面（景别·焦距·景深·构图·角度）· 时间/运动（运镜·节奏·时长）· 影调/情绪（光影·色彩）。 |
| **A/B/C 方案 (scheme)** | 生成的 ≤3 个差异化镜头脚本，对应 ≤3 个方向。 |
| **Critic** | 一致性审校 agent：耦合硬规则 + serves 校验 + LLM 判定（机制链忠实 / 易混淆误用 / 双极轴自洽）。 |
| **检索增强** | strategy 节点尽力查方案库，命中附加为参考、失败/为空不阻塞（ADR-0010，原"召回/OOD 兜底"概念废止）。 |
| **飞轮** | 用户采纳 / 编辑的脚本连同意图回写方案库，库有量后检索增强自然生效。 |
| **Orchestrator** | 贯穿全程的编排者 = LangGraph 图本身（状态机 / 路由 / 收敛门控）。 |
| **widget** | 对齐 agent 抛给前端的控件：single / multi / slider / freetext / confirm。 |
| **服务端驱动 UI** | 前端只是 widget 的通用渲染器，控件由后端 agent 决定。 |
| **人在环 (HITL)** | 对齐多轮、A/B/C 选择两处暂停等用户；LangGraph `interrupt` 实现。 |
| **ADR** | Architecture Decision Record，决策记录，见 [`decisions.md`](decisions.md)。 |
